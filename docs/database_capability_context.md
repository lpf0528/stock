## 根因与当前限制

历史上 `instock/job/indicators_data_daily_job.py` 从东方财富全市场实时行情开始执行。该链路调用 `push2.eastmoney.com/api/qt/clist/get`；当前网络出口仍会对该 API 连接返回 curl 56（连接被对端关闭）。

已验证的情况：

- 东方财富网页行情可在浏览器打开；
- `push2` API 的主节点及 `82`、`79` 备用节点均被关闭；
- HTTP/1.1、HTTP/2、Cookie/滑块验证和重试均未恢复 API 可用性。

资金流的同花顺降级策略：

- `STOCK_FUND_FLOW_SOURCE=ths`（默认）使用同花顺公开个股资金流排行榜；`STOCK_SECTOR_FUND_FLOW_SOURCE=ths`（默认）使用同花顺公开板块（行业/概念）资金流排行榜；`auto` 先尝试东方财富，失败后切至同花顺；`eastmoney` 则只使用旧源。
- 同花顺行业/概念资金流提供今日、5 日、10 日榜单，系统将其净额写入主力净流入字段（单位：元），并由“净额 ÷ (流入+流出)”推导净占比，今日榜附带领涨股。
- 同花顺未提供超大单/大单/中单/小单的拆分，不得填充或推断这些字段；它们保持空值。因此该表中的同花顺数据与东方财富原始口径不可混作精确同比。

2026-08-15 已接入新浪财经高可用历史日线源并设为默认/自动回退（`STOCK_MARKET_DATA_SOURCE=sina`）：支持新浪/腾讯多通道自动降级容灾，彻底解决腾讯/东财 WAF 拦截 501 与网络代理冲突。项目统一股票池默认仅包含 `60`、`00` 开头代码；可在系统环境变量或项目根目录 `.env` 中设置 `STOCK_CODE_PREFIXES=60,00`。该配置同时作用于每日股票行情入库、历史日线下载，以及由历史日线驱动的指标、策略、回测和 K 线形态作业；设为 `all`（或 `*`）才显式取消该限制。

同花顺板块数据方面：概念成分股及行业/概念历史可真实读取；行业成分股详情的连续 Ajax 分页会不定期返回 403 或 200 空挑战页。采集器会有限退避后整体失败，拒绝写入残缺全量名单。

### 运行定位建议

在全量腾讯历史回补、指标、策略和回测结果落库前，项目仍应定位为“基于已有选股、行情快照、行业/概念资金流、龙虎榜、涨停题材和抢筹数据的分析工具”，而不是已经全面恢复指标信号、形态识别和回测结果的全自动量化系统。

不建议删除指标、形态或策略模块；它们是数据链路恢复后的核心能力。恢复顺序应为：全市场行情/日线数据 → 指标 → K 线形态 → 策略 → 回测。
