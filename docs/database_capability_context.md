## 当前缺失：不要假设这些功能已可用

以下表在数据库中**不存在**，相应 Web 页面、任务或分析不能依赖其数据：

- 每日股票/ETF 行情：`cn_stock_spot`、`cn_etf_spot`
- 指标及买卖信号：`cn_stock_indicators`、`cn_stock_indicators_buy`、`cn_stock_indicators_sell`
- 策略、回测、K 线形态相关表
- 股票外键/基础历史数据相关表（如 `cn_stock_foreign_key`）
- 其他未在实际 `SHOW TABLES` 结果中出现的代码定义表

## 根因与当前限制

`instock/job/indicators_data_daily_job.py` 从全市场实时行情开始执行。该链路调用东方财富 `push2.eastmoney.com/api/qt/clist/get`；当前网络出口会对该 API 连接返回 curl 56（连接被对端关闭）。

已验证的情况：

- 东方财富网页行情可在浏览器打开；
- `push2` API 的主节点及 `82`、`79` 备用节点均被关闭；
- HTTP/1.1、HTTP/2、Cookie/滑块验证和重试均未恢复 API 可用性。

因此，在修复网络出口、配置大陆可用代理，或替换全市场行情来源前，**不要反复运行指标、每日股票行情、依赖实时股票池的策略/回测任务**；它们不会产生可靠结果。

## 后续 Agent 的推荐工作顺序

1. 优先围绕上述“已有数据”开展选股、行业/概念资金流、龙虎榜、涨停题材和抢筹分析。
2. 任何依赖 `cn_stock_spot` 或 `cn_stock_indicators` 的功能，先检查表是否已创建且最新交易日有数据。
3. 修复实时股票池来源后，依次补跑：基础表初始化 → 每日股票行情 → 指标 → 策略/回测/形态任务。
4. 将本文件作为运行状态上下文；重新补数后必须更新表行数与最新日期。

## 核心量化功能的当前价值判断

| 功能 | 当前可用性 | 判断 |
| --- | --- | --- |
| 根据指标判定可能买入/卖出的股票 | 不可用 | `cn_stock_indicators`、`cn_stock_indicators_buy` 和 `cn_stock_indicators_sell` 均不存在；指标任务又依赖当前不可用的全市场实时股票池。逻辑本身仍有价值，恢复行情/日线数据后可重新用于全市场技术信号筛选。 |

### 运行定位建议

在实时行情和日线数据源恢复前，项目应暂时定位为“基于已有选股、行业/概念资金流、龙虎榜、涨停题材和抢筹数据的分析工具”，而不是可稳定产出指标信号、形态识别和回测结果的全自动量化系统。

不建议删除指标、形态或策略模块；它们是数据链路恢复后的核心能力。恢复顺序应为：全市场行情/日线数据 → 指标 → K 线形态 → 策略 → 回测。
