## 总结

- 数据库当前有 **13 张表**。
- 最近交易日（2026-08-12）有数据的功能主要是：腾讯全市场快照、首批技术指标、选股、龙虎榜、分红、大宗交易、涨停原因、早/尾盘抢筹、行业/概念资金流。
- 东方财富 `push2.eastmoney.com` 仍会关闭连接；全市场快照已改由腾讯公开行情直连，且不继承本机代理。腾讯日线可支撑指标/回测的历史输入，但全量历史回补尚未执行。
- `cn_stock_indicators` 已有受控首批 15 条真实指标；买卖信号、策略和回测结果表仍未生成，不能据此宣称全市场策略/回测已恢复。

## 当前缺失：不要假设这些功能已可用

以下表在数据库中**不存在**，相应 Web 页面、任务或分析不能依赖其数据：

- ETF 每日行情：`cn_etf_spot`
- 指标买卖信号：`cn_stock_indicators_buy`、`cn_stock_indicators_sell`
- 策略、回测、K 线形态相关表
- 股票外键/基础历史数据相关表（如 `cn_stock_foreign_key`）
- 其他未在实际 `SHOW TABLES` 结果中出现的代码定义表

## 根因与当前限制

历史上 `instock/job/indicators_data_daily_job.py` 从东方财富全市场实时行情开始执行。该链路调用 `push2.eastmoney.com/api/qt/clist/get`；当前网络出口仍会对该 API 连接返回 curl 56（连接被对端关闭）。

已验证的情况：

- 东方财富网页行情可在浏览器打开；
- `push2` API 的主节点及 `82`、`79` 备用节点均被关闭；
- HTTP/1.1、HTTP/2、Cookie/滑块验证和重试均未恢复 API 可用性。

2026-08-12 已接入腾讯快照与日线：`STOCK_MARKET_DATA_SOURCE` 默认 `tencent`，并以来源隔离缓存和默认 4 路历史下载保护上游。全量指标、策略和回测仍须先以有限批次完成历史回补与数据库行数验收，**不要直接以高并发运行全市场作业**。

同花顺板块数据方面：概念成分股及行业/概念历史可真实读取；行业成分股详情的连续 Ajax 分页会不定期返回 403 或 200 空挑战页。采集器会有限退避后整体失败，拒绝写入残缺全量名单。

## 后续 Agent 的推荐工作顺序

1. 优先围绕上述“已有数据”开展选股、行业/概念资金流、龙虎榜、涨停题材和抢筹分析。
2. 任何依赖 `cn_stock_spot` 或 `cn_stock_indicators` 的功能，先检查表是否已创建且最新交易日有数据。
3. 已完成基础表初始化与每日股票行情；下一步以受控并发回补腾讯历史日线，按批次验收后依次运行指标 → 策略/回测/形态任务。
4. 将本文件作为运行状态上下文；重新补数后必须更新表行数与最新日期。

### 运行定位建议

在全量腾讯历史回补、指标、策略和回测结果落库前，项目仍应定位为“基于已有选股、行情快照、行业/概念资金流、龙虎榜、涨停题材和抢筹数据的分析工具”，而不是已经全面恢复指标信号、形态识别和回测结果的全自动量化系统。

不建议删除指标、形态或策略模块；它们是数据链路恢复后的核心能力。恢复顺序应为：全市场行情/日线数据 → 指标 → K 线形态 → 策略 → 回测。
